# Instruction maintenance

> Partially adapted from the Anthropic official plugin example `claude-md-management/skills/claude-md-improver` (Apache-2.0); see THIRD_PARTY_NOTICES.md.

Quality dimensions: actual effective scope, factual accuracy, executability, non-obvious value, concision, consistency across rules; choose dimensions per the file's purpose — no percentage scoring and no requirement to fill every slot in every file.
Report specific locations, problems, and consequences; verify file paths and command provenance, mark static inference and real execution separately — never "run it in your head" and then report tests passing. Focus on identifying repeated confirmations, over-broad triggers, duplicate gates, conflicts with authorization, and platform mismatches; a stronger model does not invalidate environment/behavioral acceptance contracts.
Update rules: additions, deletions, merges, and migrations are allowed, each serving the user's goal; durable entry points keep only stable contracts, non-obvious facts, and accurate commands. Preserve existing user edits; audits are read-only, authorized edits are not re-submitted for approval, and out-of-scope or key-contract changes need clarification. Verify referenced paths, command semantics, diffs, and generation consistency; do not run installs or deployments to "verify documentation" without necessity; zero modification is also a valid result.
Optional outline (the template is a menu, not to be filled in full): project entry, key contracts, environment/run entries, narrowest verification, genuinely non-obvious pitfalls. Global files keep stable personal preferences; the project root keeps navigation; domain detail goes in the applicable subdirectory; state and history go into the existing recovery surface. The Codex global file is `$CODEX_HOME/AGENTS.md` or `AGENTS.override.md` (default `~/.codex`); Claude Code uses its CLAUDE.md configuration; after modifying Cursor's canonical rules, sync the adaptation surface. Do not port discovery paths across runtimes.
