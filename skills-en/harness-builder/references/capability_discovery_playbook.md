# Capability discovery
First check the tools already exposed and the user-specified capabilities, then do targeted discovery tied to a real gap. When the user only asks to finish a task and the existing tools suffice, do not search skill catalogs.
Scanning scripts only provide candidate evidence, not a complete inventory of capabilities already loaded in the runtime. After reading the candidate resources, evaluate platform, permissions, duplication, maintenance and probes.
Installation follows existing scope authorization; read-only advice writes no configuration. When no candidate can be found, continue the work that is still completable and report the verification gap accurately.
