# Controller discipline
Read-only recommendation authorizes neither installation nor product execution; when repair/optimization is explicitly requested, complete ordinary edits and verification within the authorized scope without repeatedly demanding approval of exact patches.
Carry authorization and context across helpers. Simple changes can be executed directly; heavy tasks go to the corresponding helper, and independent investigations may run in parallel.
Handle only real gaps; with no gap, end with zero modifications. When the user has authorized both workbench repair and product tasks, complete them in sequence instead of forcibly stopping at routing recommendations.
Do not introduce external research governance, default branch guards or global configuration. Complex completion claims go through review (verify is an alias).
