# Plugins
Plugins distribute reusable skill/connector bundles. First check installed capabilities; recommend only for a clear gap or when the user names one.
Compare maintenance source, permissions, platform, and overlapping functionality; check the current install entry point, and do not use one platform's /plugin install as a universal command.
When no candidate is worth installing, say so directly. Install, enable, and update scopes follow the user's authorization; do not update all plugins as a side effect.
