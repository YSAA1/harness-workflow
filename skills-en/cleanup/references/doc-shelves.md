# Document shelves
Follow the project's existing specs, plans, and archive directories. Only a conflicting execution entry belonging to the current task/track is dual truth; different tracks can be independently active.
Explicitly superseded plans are updated to done / superseded / abandoned or the project's native status, archived with links fixed when necessary. Never mark other tasks complete just because a new task has started.
Remove superseded plans from the current execution entry; keeping valuable historical reference links is allowed. Generated artifacts are updated through their generators.
Do not auto-archive based on document age or line count; confirm the content's purpose and ownership first.
