# Premature completion
Avoid treating a tool's successful exit, the existence of files, green local tests, or the author's narrative as final behavioral evidence.
Re-check affected claims when relevant code, the environment, or inputs later change; unrelated file modifications do not automatically invalidate all evidence.
Report missing required conditions as unknown; you must not go ready with unresolved blocking issues. Non-blocking improvements should not indefinitely extend a task whose goal is already satisfied.
review uniformly performs the structure and evidence judgment; verify is no longer an independent completion gate.
