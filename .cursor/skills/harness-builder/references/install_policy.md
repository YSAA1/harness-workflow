# Install policy
先查实际目标运行时、canonical source、已安装能力和用户范围；不默认安装全套模板或固定八文件。
修复已授权范围内的本地文件可直接执行，安装/启用外部能力需已有相应授权。Required 是推荐等级，不是权限。只读建议保持只读；新范围、重要取舍或不可逆动作才需要 USER CHECKPOINT。
以最小可验证 diff 更新 canonical source，再用已存在安装/适配命令同步镜像。安装前准备可审阅内容和恢复方式，保留无关用户修改。
只选择必要模板。hooks、MCP、子代理定义默认不安装，需针对目标平台和项目合同验证。
若源为远端目录而当前修改尚未发布，用目标运行时支持的本地安装途径；不得谎称重新拉取远端就包含本地修改。
