# Recommendation matrix
多类工作台改造可用一张表：缺口/证据、最小处理、负责人、验证。单项小修可用短句，空类别无需占位。
Required / Recommended / Deferred / Rejected 描述优先级与选择，不授予安装权限。
检查与当前目标相关的入口、恢复、验证或能力；不用为 skills/hooks/MCP/subagents/plugins/CI 每类凑一行。
复杂行可交给对应 helper；小指针修复无需调用完整流程。已有授权在 helper 间传递，避免重复 USER CHECKPOINT。
可用已有能力解决时不新增工具；候选事实需要当前信息时查官方来源。
