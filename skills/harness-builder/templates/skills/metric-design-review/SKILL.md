# Metric Design Review

## Use when

Use when selecting or changing metrics, offline evals, dashboards, or acceptance criteria.

## Checklist

- Define user-facing success.
- Check metric validity and blind spots.
- Compare to baseline and counter-metric.
- State non-goals and failure modes.

## Output

```markdown
# Finding

# Evidence

# Risks

# Recommended action

# Confidence
```

## Rules

- Do not claim validity without evidence.
- Prefer small reproducible checks.
- Record unresolved risk instead of hiding it.
