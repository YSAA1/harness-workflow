# Reward Function Review

## Use when

Use when changing or reviewing reward functions, shaping, penalties, or task success criteria.

## Checklist

- Identify optimization target and proxy risks.
- Check for reward hacking paths.
- Compare against baseline behavior.
- Record counter-hypotheses and tests.

## Output

```markdown
# Finding

# Evidence

# Risks

# Recommended action

# Confidence
```

## Rules

- Do not claim validity without evidence.
- Prefer small reproducible checks.
- Record unresolved risk instead of hiding it.
