# Instruction maintenance

> 部分内容改编自 Anthropic 官方插件示例 `claude-md-management/skills/claude-md-improver`（Apache-2.0），见 THIRD_PARTY_NOTICES.md。

质量维度：实际生效范围、事实准确性、可执行性、非显然价值、简洁性、规则间一致性；按文件用途选择维度，不要求百分制或每个文件填满。
报告具体位置、问题和后果；核对文件路径与命令来源，静态推断与真实执行分别标记，不能"脑内运行"后报告测试通过。重点识别重复确认、过宽触发、重复闸门、与授权冲突及平台失配；模型变强不使环境/行为验收合同失效。
更新规则：允许新增、删减、合并和迁移，每项服务用户目标；持久入口只保留稳定合同、非显然事实和准确命令。保留既有用户改动；审计只读，已授权编辑不重复求批，超范围或关键合同改变需澄清。验证引用路径、命令语义、diff 和生成一致性；没有必要时不运行安装或部署来"验证文档"；零修改也是有效结果。
可选大纲（模板是菜单，不要求填满）：项目入口、关键合同、环境/运行入口、最窄验证、真正非显然的陷阱。全局文件保留稳定个人偏好；项目根保留导航；领域细节放适用子目录；状态和历史放已有恢复面。Codex 全局为 `$CODEX_HOME/AGENTS.md` 或 `AGENTS.override.md`（默认 `~/.codex`）；Claude Code 用其 CLAUDE.md 配置；Cursor 修改 canonical rules 后同步适配面。不要跨运行时套用发现路径。
