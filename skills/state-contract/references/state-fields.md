# State Fields

Workflow skills should ask for fields, not specific files.

| Field | Needed by | Meaning |
|---|---|---|
| objective | plan, resume, review | What the work is trying to achieve |
| active_slice | implement, review, verify | The one current unit of work |
| non_goals | implement, review | What must not be done in this slice |
| success_criteria | review, verify, cleanup | What must be true to close |
| verification_path | implement, verify | Commands or checks to run |
| evidence_log | review, verify, save-session | Fresh command evidence |
| decisions | diagnose, review, cleanup | Accepted technical decisions |
| rejected_options | brainstorm, diagnose, review | Paths not to retry |
| risks | all tracked skills | Known risks and residual uncertainty |
| blockers | diagnose, save-session | External or capability blockers |
| next_actions | resume, save-session | First concrete next step |
