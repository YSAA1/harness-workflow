# AutoResearch 研究循环

开放问题按轮推进：每轮一个可证伪假设，取证、对抗、蒸馏；推进靠排除法，边界靠预算，停止要诚实。总控负责轮编排、授权档位、预算与停止判定；取证（阅读、检索、运行实验）由本 skill 直接执行，需要改代码才调 `implement`，不在轮内调 `ship`（收尾由本 skill 统一负责）。

## 依赖与降级

配套 skill（`plan`/`implement`/`review`/`cleanup`）或恢复面缺失时按其协议精神自查自收：无恢复面则日志单文件即轨道，不强建 `.harness/`——默认路径 `docs/research/YYYY-MM-DD--<topic>.md`（项目有 research/notes 惯例跟随），日志头 Track 行即自登记轨道，重入本 skill 先检索 `docs/research/` 既有日志；无 lessons 面则蒸馏条目记日志末节。研究问题本身是用户设计取舍且阻碍继续时才转 `brainstorm`，转出后本 skill 结束。

## 授权档位

| 档位 | 规则 |
| --- | --- |
| `default` | 首轮获批包必须用户批准；后续轮自动放行 |
| `strict` | 每轮获批包都需用户批准 |
| `全权` | 用户显式声明后免批；获批包仍落日志备查 |

档位只管轮次确认，不扩大工具、外部写入或费用授权——允许动作、数据范围与预算写进首个获批包，后续方法超出范围时停下请求新增授权。需批准的轮次：获批包写完停等用户原话（原话回填日志）才开始取证；获批包此后只追加修订并保留前后差异。

## 预算

默认 3 轮、每轮 1 次有成本实验，用户可调。假设、预测、方法的实质变更与有成本实验的重跑都计入预算；轮内修补只复验受影响部分。

## 循环

首轮前：读 lessons 与既有日志；有恢复面则 `plan` 建轨道（work_index 行 + 日志）。每轮四段：

1. **立获批包**：写进日志——可证伪假设、预测（足以区分本轮竞争解释，不扩大也不偷换用户范围）、验证方式、成功判据、允许动作与预算。完成判据：包内件件齐、按档位获批。
2. **取证**：直接执行阅读/检索/实验，需改代码走 `implement`（实验子任务独立，不动研究主轨道）；环境有 subagent 或 cli-delegate 等只读委派能力时，批量阅读/检索可委派后台执行，主循环只持有假设与裁决——委派结果仍是 claim，关键观察回主会话核对来源与时点后才落日志。完成判据：观察连同来源与获取时点落日志。
3. **对抗验证**：`review` 协议 + 独立攻击（lens 见 `references/adversarial-lenses.md`），**重开提案本身列入必审对象**。降级自审必须记录具体攻击与反例尝试，输出标注 independent / self。完成判据：每条关键结论带攻击记录与独立/自审标注。
4. **蒸馏**：日志记一节（假设 → 预测与观察 → 对抗裁决 → 结论）；lessons 只收带触发条件的非显然经验，「无新增」是合法结论并照记。完成判据：日志节完整。

## 停止状态（任一轮末可进）

`answered`（原问题被覆盖且证据充分——唯一可称研究完成的终态）／`inconclusive`（证据不足，如实报告未能得出的结论）／`blocked`（外部依赖不可得）／`budget-exhausted`（预算尽）／`cancelled`（用户叫停）。

**重开**下一轮须在对抗审查下交出排除法三问：本轮排除了什么（附证据）、尚未解决的剩余解释、下一实验如何区分它们——原问题与范围不变（背景节固定）。禁止把未覆盖的原始要求降格为「遗留」：只能报告部分回答，或在剩余预算内继续；与原问题不同向的相邻新问题才记「遗留」，用户显式加问另立轨道。

收敛或停止后**先写完终态与结论**，再走 `cleanup` 收尾；研究日志是交付物，不随退休四步删除（退休只处理临时计划与 scratch；无 git 环境保留日志并记录终态）。
