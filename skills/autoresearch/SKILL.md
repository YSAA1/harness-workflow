# AutoResearch 研究循环

用户交办一个目标或问题——方案未知没关系。本 skill 独立跑完：每轮「研究 → 干活 → 审核 → 蒸馏」，对照完成判据看完成没有，没完成就过排除法三问续轮。入口一句话，循环零打扰；与 deep research 的区别是**干活是一等公民**——跑实验、写测量脚本、改代码验证假设都是正常取证。需改代码走 `implement`（实验子任务独立轨道，不动研究主轨道），不在轮内调 `ship`（收尾由本 skill 统一负责）。

## 入口

- `autoresearch <目标/问题>`（可附材料）：立项即开跑。
- `autoresearch <研究日志路径>`：目标已在日志头部，直接续跑；重入先检索 `docs/research/` 既有日志。

## 立项摸底（planner）

1. 需求定成一句可交付目标（逐字引用用户原话，原话未覆盖的推断须标注），落日志（默认 `docs/research/YYYY-MM-DD--<topic>.md`，项目有 research/notes 惯例跟随）。头部背景节＝一句话目标＋范围边界＋完成判据＋已知事实与候选解释——**全程固定**，防偷换防漂移。日志即轨道（Track 头自登记）：有恢复面则 `plan` 建行，无恢复面不强建 `.harness/`，无 lessons 面则蒸馏条目记日志末节。
2. 摸底并行做：读 lessons 与既有日志；通用检索＋平台渠道（环境装有 agent-reach 类平台读取路由时自动扩展取证面，遵循其自身协议如 doctor 体检；无则降级为通用 web 检索＋一手来源直读）。候选解释＝后续轮次要区分的竞争假设。

## 循环（每轮四段）

1. **研究**：假设包写进日志——可证伪假设、预测（足以区分本轮竞争解释，不扩大不偷换用户范围）、验证方式、成功判据。**不等批准**——防线＝背景节固定＋授权边界＋审核必审。
2. **干活**（取证执行，并行扇出：轮内独立任务并行派后台代理/subagent，主会话只持假设与裁决，有依赖才串行）：
   - 只读类：一手来源优先（官方文档、源码、spec、第一方 API）；委派结果一律是 claim，回主会话核来源＋获取时点才落账；平台社交内容（X/Reddit/播客字幕等）是线索不是定案，定案回溯一手来源；关键结论至少两个独立一手来源交叉，只有单源必须明示。
   - 动手类：本地可逆实验直接做——跑实验、写测量脚本、改代码验证（走 `implement`，实验子任务独立轨道不动主轨道）；纯阅读轮此段记「本轮无需动手」。
3. **审核**：`review` 协议＋独立攻击（lens 见 `references/adversarial-lenses.md`），**重开提案本身列入必审对象**。降级自审必须记录具体攻击与反例尝试，输出标注 independent / self。
4. **蒸馏**：日志记一节（假设→预测与观察→对抗裁决→结论）；lessons 只收带触发条件的非显然经验，「无新增」是合法结论并照记。

## 控制与停止

- **完成检查**：每轮蒸馏后对照背景节完成判据——覆盖且证据充分 → `answered`（唯一可称完成的终态）；否则过三问决定续轮或诚实停止。
- **重开三问**（对抗审查下交出）：本轮排除了什么（附证据）？尚未解决的剩余解释？下一轮如何区分？目标与范围不变（背景节固定）；未覆盖的原始要求不得降格为「遗留」——只能报告部分回答，或在剩余预算内继续；与原目标不同向的相邻新问题才记「遗留」，用户显式加问另立轨道。
- **授权边界（唯一暂停点）**：研究范围内只读、检索、本地可逆实验免批；花钱、外部写入、不可逆或生产影响——停下来问。逐轮确认是触发词选项（用户说「每轮停下来给我看」即启用）；「全权」声明后全程免停。
- **预算**：默认 3 轮 × 每轮 1 次有成本实验（检索与阅读不计入），用户可调；预算尽 → `budget-exhausted`。
- **五终态**：`answered` / `inconclusive`（证据不足，如实报告未能得出的结论）/ `blocked`（外部依赖不可得）/ `budget-exhausted` / `cancelled`（用户叫停）。

## 终态与交付

收敛或停止后**先写完终态与结论**，再走 `cleanup` 收尾。结论节按「结论先行＋逐条证据链接」书写，读者只读该节即可拿走答案。研究日志是交付物，不随退休四步删除；无 git 环境保留日志并记录终态。
