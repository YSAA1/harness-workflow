# AutoResearch 研究循环

开放问题按轮推进：每轮一个可证伪假设，实施取证、独立对抗、蒸馏继承，证据门裁决收敛或重开。总控只负责轮编排、授权档位、终止判定与降级路径，各阶段协议以对应 skill 为准（同 `ship`，只编排不新增闸门）。

## 授权档位

| 档位 | 规则 |
| --- | --- |
| `default` | 首轮 Spec 必须用户批准；后续轮由证据门自动放行，重开时说明新证据即可 |
| `strict` | 每轮 Spec 都需用户批准 |
| `全权` | 用户显式声明后免批；Spec 仍落盘备查 |

档位在调用时指定，轮间可调，未指定即 `default`。沉默不是批准，改档以用户原话为准。

## 循环（默认 3 轮上限，用户可调）

首轮开始前：读 lessons 与既有研究日志；`plan` 建研究轨道（work_index 行 + 日志文档）。每轮四段：

1. **讨论方案** → `brainstorm`：输入＝研究问题＋上轮结论；产出＝本轮 Spec（假设、验证方式、可证伪的成功判据、重开条件）。完成判据：成功判据可证伪，且按当前档位获批。
2. **实施方案** → `plan` → `implement`（单轮可交付时直接 `ship`）。完成判据：验证方式已执行，fresh evidence 落进日志。
3. **对抗验证** → `review` ＋ 独立攻击：宿主支持子代理则派新生上下文按 lens 审查（`references/adversarial-lenses.md`）；不支持则降级为新会话审查或 review 自审清单，并在日志标注降级方式。完成判据：每条关键结论带独立攻击记录或降级标注。
4. **蒸馏继承**：日志记一节（假设 → 证据 → 裁决 → 结论）；lessons 只收带触发条件的非显然经验，「无新增」是合法结论并照记；本轮 Spec 蒸馏入日志后删除（git 历史即归档）。完成判据：日志节完整、Spec 已处置、恢复面 Evidence 行指向当前状态。

## 证据门

重开下一轮须同时满足：①对抗验证或实施产生了**推翻本轮假设的新证据**；②下一轮假设比本轮更小或更具体。任一不满足即收敛——没有新证据的重开是打磨空转。

收敛条件（任一）：Spec 成功判据经对抗验证确认；轮上限到达；用户叫停。收敛后轨道走 `cleanup` 退休契约，最终结论写日志末节。

## 状态与产物

- 研究日志＝轨道记忆：`docs/plans/YYYY-MM-DD--research-<topic>.md`（模板 `templates/research-log.md`），work_index 行 primary artifact 指向它；进行中轮次的 Spec 路径写进 state.md Evidence 行保持可达。
- 跨会话中断按项目恢复面从 work_index 行接续当前轮。
- 研究轨道退休时日志与其他轨道文档同走退休四步。

## Recommended next skill

- 收敛收尾：`cleanup`；实施中根因未知：`diagnose`。
- 研究产物堆积后全仓对账：`sweep`。
