# AutoResearch 研究循环

开放问题按轮推进：每轮一个可证伪假设，实施取证、独立对抗、蒸馏继承，证据门裁决收敛或重开。总控只负责轮编排、授权档位、终止判定与降级路径，各阶段协议以对应 skill 为准（同 `ship`，只编排不新增闸门）。

## 授权档位

| 档位 | 规则 |
| --- | --- |
| `default` | 首轮获批包（假设、预测、验证方式、成功判据一并写入日志）必须用户批准；后续轮由证据门自动放行 |
| `strict` | 每轮获批包都需用户批准 |
| `全权` | 用户显式声明后免批；获批包仍落日志备查 |

档位在调用时指定，轮间可调，未指定即 `default`。沉默不是批准，改档以用户原话为准。

## 循环（默认 3 轮上限，用户可调）

首轮开始前：读 lessons 与既有研究日志；`plan` 建研究轨道（work_index 行 + 日志文档）。每轮四段：

1. **立获批包**：把本轮获批包直接写进研究日志——可证伪假设、**最弱可观察的预测**（恰好回答研究问题即可，用户没问的全称量词不加——它会给伪造 ¬P 开洞）、验证方式、成功判据。按档位需批准的轮次：写完停等用户原话，批准后才开始取证。研究问题本身是产品/设计取舍时转 `brainstorm`，转出后本 skill 结束，不在 brainstorm 里套跑循环。完成判据：四件齐、预测为最弱命题，且按当前档位获批。
2. **实施取证** → `implement`（复杂验证先 `plan`；单轮可交付时 `ship`）。完成判据：验证方式已执行，观察结果连同命令与输出位置落日志。
3. **对抗验证** → `review` ＋ 独立攻击：宿主支持子代理则派新生上下文按 lens 审查（`references/adversarial-lenses.md`）；不支持则降级为新会话审查或 review 自审清单，并在日志标注降级方式。完成判据：每条关键结论带独立攻击记录或降级标注。
4. **蒸馏继承**：日志记一节（假设 → 预测与观察 → 对抗裁决 → 结论）；lessons 只收带触发条件的非显然经验，「无新增」是合法结论并照记。完成判据：日志节完整、恢复面 Evidence 行指向当前状态。

## 证据门

重开下一轮须同时交出三件**可复核物证**（模板四槽原文，任一槽填标签或「见上」即视为未交出）：

1. **预测-观察对照**：获批包预测 P 原文，实际观察到 ¬P 原文，附命令、来源或输出路径；
2. **新**：该观察在本轮开始前的日志里不存在——同一材料的新解释不算新证据；
3. **更小**：下一假设是本轮假设的合取收紧或真子集，**且下一预测的观察范围同时收紧**。

「换角度」「补充细节」「部分证实所以继续」不构成重开。对抗段发现的措辞与歧义问题只触发本轮修补，不算推翻。假设成立但未覆盖用户问题的相邻问题记入日志「遗留」节，不开新轮；用户显式加问时另立研究轨道。

收敛条件（任一）：成功判据经对抗验证确认；轮上限到达；用户叫停。收敛后轨道走 `cleanup` 退休契约，最终结论写日志末节。

## 状态与产物

- 研究日志＝轨道唯一产物：`docs/plans/YYYY-MM-DD--research-<topic>.md`（模板 `templates/research-log.md`），work_index 行 primary artifact 指向它；假设、观察、对抗裁决、遗留全部在日志内，不逐轮另开 Spec 文件。
- 跨会话中断按项目恢复面从 work_index 行接续当前轮。
- 研究轨道退休时日志与其他轨道文档同走退休四步。

## Recommended next skill

- 收敛收尾：`cleanup`；实施中根因未知：`diagnose`。
- 研究产物堆积后全仓对账：`sweep`。
