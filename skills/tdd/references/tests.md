# 好测试与坏测试

好测试：integration 风格，通过真实公共接口驱动；一个测试一个逻辑断言；期望值来自独立来源（已知正确的字面量、算好的例子、Spec）。

坏测试 = 实现细节测试：

- mock 内部协作者、测私有方法、断言调用次数或调用顺序。
- 识别信号：行为没变、重构后测试却破裂。
- 绕过接口从旁路验证（BAD：直接调内部函数比对结构；GOOD：走公共入口断言可观察结果）。

同义反复：

- BAD：`expect(add(a, b)).toBe(a + b)` —— 期望值按实现自己的方式重算，构造性通过。
- GOOD：`expect(add(2, 3)).toBe(5)` —— 期望值是独立字面量。
