# Golden Principles Guide

Use only when Static docs and durable rules selects project-specific golden-principles docs.

Each file should cover one topic, be 30-60 lines, lead with the rule, and include DO/DON'T examples from or adapted to actual code patterns.

Common candidates: `IMPORTS.md`, `NAMING.md`, `ERROR_HANDLING.md`, `TESTING.md`, `DATA_FETCHING.md`, and `LOGGING.md`.
