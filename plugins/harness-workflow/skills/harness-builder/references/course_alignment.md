# Learn Harness Engineering Alignment

Use this file as a coverage checklist. The goal is not to generate every artifact. The goal is to explicitly consider each harness engineering dimension and adopt, defer, or reject it for the current project.

Dimensions include capable-agent failure layers, harness subsystems, repository as system of record, instruction splitting, state continuity, initialization, scope control, feature lists, completion gates, E2E smoke, observability, and clean state.

Use a coverage table: Course dimension, Adopt/Defer/Reject, Harness artifact, Reason.
