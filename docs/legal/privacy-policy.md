# Privacy Policy

Harness Workflow is a local agent workflow plugin. It does not collect, transmit, sell, or share personal data by itself.

The plugin contains workflow instructions, templates, scripts, and validation checks. Any data access comes from the host agent, user-approved tools, or commands that the user runs in their own environment.

For questions, use the project repository: https://github.com/YSAA1/harness-workflow
