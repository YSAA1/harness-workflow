## 一、定位（一句话）

把开放问题跑成有界的「**研究 → 干活 → 审核 → 蒸馏**」来回循环：研究段立假设并查证据，干活段动手验证（跑实验、改代码、测量），审核段对抗裁决，蒸馏段落账——直到五个诚实终态之一。

与 GPT-Researcher 的本质区别：它的 executor 只爬取和阅读（deep research）；本循环的 executor **可以动手**——实验脚本、分支上的代码改动、性能测量都是取证的一等公民。

## 二、继承与差异（对照 GPT-Researcher）

| GPT-Researcher | 本方案 | 裁决 |
| --- | --- | --- |
| planner 生成覆盖性研究问题 | 立项摸底＋每轮研究段立假设包 | 继承，同构 |
| executor ×N 并行爬取 | 研究段只读取证＋干活段动手实验，均并行扇出 | 继承并行；**扩展为可动手** |
| publisher 聚合报告 | 蒸馏段＋终态结论节（结论先行+证据链接） | 继承，轻量单文件版 |
| depth/breadth 可配置 | 轮次预算（默认 3 轮 × 每轮 1 次有成本实验，可调） | 继承，同构 |
| 多源去偏（20+ 来源） | 关键结论 ≥2 独立一手来源，单源明示 | 继承 |
| 一句话入口、流程中无 human-in-the-loop | 同（仅风险触发暂停） | 继承 |
| （无审核环节） | **审核段：对抗验证，重开提案必审** | 本方案增项 |
| （无诚实终态，问题穷尽即停） | **五终态：answered/inconclusive/blocked/budget-exhausted/cancelled** | 本方案增项 |
| 树状广度探索，无方向论证 | **排除法三问才许重开** | 本方案增项 |

## 三、用户视角流程（最终版）

```text
你说一句话：「研究 X，查到有结论为止」（可附材料）
   ↓ 直接开跑（零仪式，无批准触点）
P0 立项摸底（planner）
   一句话问题＋边界 → 日志头部（背景节，全程固定）
   读 lessons/旧日志 ＋ 并行检索（含平台渠道）→ 已知事实＋候选解释入背景节
   ↓
自动循环（每轮四段，日志即轨道，中间零打扰）
   ① 研究：可证伪假设＋预测＋验证方式＋成功判据入日志（不等批）；
      只读取证并行扇出（通用检索＋平台渠道），claim 回主会话核来源+时点
   ② 干活：假设需要动手验证时执行——跑实验、写测量脚本、改代码验证
      （走 implement 独立子任务，不动研究主轨道）；纯阅读型轮此段记「本轮无需动手」
   ③ 审核：对抗验证——攻击视角审本轮结论，重开提案本身必审，标 independent/self
   ④ 蒸馏：假设→观察→裁决→结论入日志；可复用经验进 lessons
   ↓ 循环控制
   重开须过排除法三问：排除了什么（附证据）？还剩什么没区分？下轮怎么区分？
   只停四种情况：越界授权（花钱/外部写入/不可逆或生产影响）、blocked、预算尽、你叫停
   ↓
终态（publisher）
   五终态之一 ＋ 结论节（结论先行＋逐条证据链接，读者只读这节拿走答案）
   ↓
交付＝这份研究日志；会话断了 →「autoresearch <日志路径>」直接续跑
你的全程参与＝开场一句话＋（可选）中途叫停。没有别的必选触点。
```

## 四、协议条款（按主题分组）

**入口与产物**

- T1 一句话零仪式入口：把需求定成一句可交付研究问题即开跑（同 research skill 第 1 步）；`autoresearch <既有日志路径>` 续跑为一等入口。
- T2 日志即 goal、产物即轨道：头部＝一句话问题＋范围边界＋已知事实（背景节固定全程不变，防偷换防漂移）；落点 `docs/research/YYYY-MM-DD--<topic>.md`，Track 头自登记，sweep 自足交付物守卫沿用；不新增文档类别。
- T3 结论可读性：answered 终态的结论节按「结论先行＋逐条证据链接」书写，读者不读轮次过程也能拿走答案；不另造独立报告。

**循环四段（每轮）**

- T4 研究段：假设包（可证伪假设/预测足以区分竞争解释/验证方式/成功判据）写日志**不等批**——防线＝背景节固定（T2）＋授权边界（T8）＋审核必审（T6）。
- T5 干活段：实验性动手是取证一等公民——本地、可逆的实验脚本与代码改动直接做（改代码走 `implement`，实验子任务独立轨道）；纯阅读型轮记「本轮无需动手」（段可空，显式记录）。
- T6 审核段：对抗验证＋独立攻击视角，**重开提案本身必审**；降级自审必须记录具体攻击与反例尝试，标注 independent/self。
- T7 蒸馏段：假设→预测与观察→对抗裁决→结论完整入日志；lessons 只收带触发条件的非显然经验，「无新增」是合法结论。

**循环控制与停止**

- T8 授权边界（唯一风险触发暂停点）：研究范围内只读/检索/本地可逆实验免批；**花钱、外部写入、不可逆或生产影响——停下来问**。逐轮确认降为触发词（「每轮停下来给我看」），「全权」全程免。
- T9 预算：默认 3 轮 × 每轮 1 次有成本实验，可调；检索与阅读不计入；预算尽 → budget-exhausted。
- T10 重开纪律：排除法三问（附证据），原问题与范围不变（背景节固定）；未覆盖的原始要求不得降格为「遗留」，只能报告部分回答或在剩余预算内继续。

**取证执行**

- T11 并行扇出：轮内相互独立的检索/阅读/实验任务并行派发（后台代理/subagent），主会话只持假设与裁决；串行仅在有依赖时。
- T12 来源纪律：一手来源优先（官方文档/源码/spec/第一方 API）；关键结论 ≥2 独立一手来源交叉，单源必须明示；平台社交内容（X/Reddit/播客字幕等）是线索不是定案，定案回溯一手来源；委派结果一律是 claim，回主会话核来源＋获取时点才落账。
- T13 渠道层：通用 web 检索为基线；环境装有平台读取路由类 skill（如 agent-reach：15 平台，X/Reddit/YouTube·B站字幕/播客转录/GitHub code search 等）时取证面自动扩展；渠道是环境能力，无则降级，协议不依赖任何特定第三方 skill；使用时遵循该 skill 自身协议（如 agent-reach 的 doctor 体检）。
