# Claude Code 科研快速上手

本教程面向**理工科研究生**，目标是让你在读完这 6 节之后，能把 Claude Code 用进日常科研工作里——读代码、写实验、处理数据、管理长周期项目——而不需要学任何复杂配置。

## 前置条件

- 已安装 Claude Code（[官方安装指南](https://docs.claude.codes/install)）
- 有一个科研代码仓库（自己的实验代码，或者 clone 的开源论文代码）
- 习惯在终端里工作（git、conda、跑脚本）

## 学习路径

教程按照一个研究生"小李"的真实科研节奏展开。他在做一个图像分类的实验项目，所有示例都围绕这个场景。

| 顺序 | 模块 | 解决什么问题 | 预计时间 |
|------|------|-------------|---------|
| 1 | [认识 Claude Code + 上手](01-intro-and-setup.md) | "这到底是什么？怎么开始？" | 10 分钟 |
| 2 | [CLAUDE.md：最重要的一步](02-claude-md.md) | "怎么让 CC 认识我的项目？" | 15 分钟 |
| 3 | [有效沟通：给上下文、给验证](03-effective-communication.md) | "怎么跟 CC 说话它才懂？" | 15 分钟 |
| 4 | [科研日常实战](04-daily-research-workflow.md) | "读代码、写实验、处理数据——怎么一气呵成？" | 20 分钟 |
| 5 | [会话管理](05-session-management.md) | "实验跑了好几天，怎么不丢上下文？" | 20 分钟 |
| 6 | [常见失败模式 + 下一步](06-pitfalls-and-next.md) | "别人踩过的坑我怎么避开？学完基础版之后学什么？" | 10 分钟 |

## 阅读建议

- **顺序阅读**：6 个模块围绕同一个项目场景展开，后面的模块会引用前面的概念。跳着读会丢失上下文。
- **边读边试**：每个模块都有可操作的具体示例。在你自己项目上跟着做一遍，比读三遍更有用。
- **把这 6 节当作"最小可行认知"**：读完你就能覆盖 80% 的科研日常场景。剩下 20% 的进阶用法——skills、hooks、subagents 自定义、对抗验证、长周期项目管理——见[进阶版教程](../claude-code-advanced/)。

## 术语约定

| 术语 | 含义 |
|------|------|
| CC | Claude Code，本教程统一用 CC 指代 |
| 会话（session） | 一次 CC 对话，从启动到退出 |
| 上下文（context） | CC 在当前会话中"知道"的所有内容——系统提示、CLAUDE.md、对话历史、读取的文件、命令输出 |
| 压缩（compaction） | CC 把长对话历史总结成简短摘要，释放上下文空间 |
