## 改动门槛

技能行为的修改须附**观察到的失败**：在真实会话里跑了什么、技能做了什么、本来期望什么。「这样会更好」式的设想不够；借鉴上游或纸面推演的改动须标注「未首跑」，首跑后回填观察结果。
